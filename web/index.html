全部应用

已安装应用

可升级应用

应用脚本有新版本时会出现在这里，点击「升级」会重新执行安装脚本（保留配置与数据）。

下载源

安装时自动测速选择的最优源；如需更换，编辑 /etc/nanopanel/mirror.conf 后重启面板服务。

应用健康检测

定时检查已安装应用的 systemd 单元；从「运行中」变为「已停止」或恢复时， 会推送 Webhook 通知（需在「设置 → 通知」勾选「应用掉线 / 恢复」事件）并写入面板日志。

温度告警

按检测间隔读取设备热区温度，超过阈值时推送一次「温度告警」通知， 回落后会再通知已回落（滞回带 5℃，避免临界温度反复告警）。 阈值 0 表示关闭。需在「设置 → 通知」勾选「温度告警」事件。

Webhook 通知

推送失败不影响面板操作本身；在上方勾选要推送的事件类别。
应用健康检测与掉线告警的开关在「应用商店 → 设置」里。

修改密码

修改后其他设备的登录态会全部失效。

登录会话

退出当前浏览器保存的登录凭据。

HTTPS 访问

开启后自动生成自签证书（有效期 10 年，覆盖本机主机名与全部网卡地址），面板重启后以 HTTPS 提供服务。 浏览器首次访问需信任证书；关闭后同样需要重启面板生效。

系统操作

重启会中断所有正在运行的服务，请谨慎操作。
